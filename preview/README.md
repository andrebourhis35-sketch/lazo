# Vista previa del isotipo

Abrir isotipo.html en un navegador mediante doble clic; no requiere servidor ni support.js. Manrope se carga desde Google Fonts si hay conexión; sin conexión se utiliza la fuente del sistema.

Derivada de branding/lienzo/Definitivo.dc.html. Conserva el SVG y la composición originales, retirando únicamente las envolturas del entorno de Claude y agregando controles de escala. No altera los originales.

Usar Tamaño real (100%) con zoom del navegador al 100% para evaluar los tamaños pequeños. Ajustar tablero reduce el conjunto para verlo completo y no sirve para juzgar legibilidad a escala real.

Verificación de Codex: apertura en Chrome y comprobación visual del tablero en modo ajustado. Aprobación de marca y revisión detallada a escala real pendientes del usuario.
