# LAZO · Prototipo de Conversaciones

Abrir index.html o servir esta carpeta con un servidor estático. HTML, CSS y JavaScript sin dependencias de compilación. Manrope se solicita a Google Fonts; existe fuente alternativa del sistema.

Incluye seis contactos ficticios, búsqueda por nombre o último mensaje, filtros, selección de chat, mensajes simulados (Enter envía; Shift+Enter añade una línea), sugerencia predefinida editable, resolución/reapertura, etapa comercial y notas. Los cambios se guardan en localStorage de este navegador; Restablecer demo recupera los datos iniciales.

No conecta WhatsApp, IA, usuarios ni base de datos. Las secciones futuras están deshabilitadas. Correos example.com y conversaciones son ficticios. El símbolo provisional deriva del SVG importado de Claude; no implica aprobación del isotipo. Los diseños originales en branding/lienzo/ se conservan intactos.
